# Kryteria ofert pracy

## Dopasowanie
Źródło: profil Marcina na LinkedIn (doświadczenie i umiejętności). Rdzeń: administracja VMware,
Active Directory, Windows Server, SCOM, Veeam, Exchange, PKI, skrypty (PowerShell).

## Typ pracodawcy
- Priorytet: sektor publiczny / tzw. budżetówka (urzędy, administracja, instytucje państwowe,
  jednostki podległe, spółki Skarbu Państwa, uczelnie, szpitale).
- Dopuszczalne: firmy spoza sektora publicznego (te same filtry poniżej).

## Tryb pracy (wymagane)
- Zdalnie (remote) lub hybrydowo. Odrzucaj oferty w pełni stacjonarne.

## Filtr językowy (odrzucać)
1. Oferty napisane po angielsku.
2. Oferty, w których w opisie wymagany jest język angielski na poziomie B2 lub wyższym
   (B2, C1, C2, „fluent", „advanced", „biegły" itp.).
- Oferta w języku polskim bez wymogu angielskiego, albo z angielskim niżej niż B2 / „mile widziany" – zostaje.
- Przypadki niejednoznaczne („dobra znajomość angielskiego" bez poziomu) – nie odrzucaj,
  oznacz w raporcie jako „do sprawdzenia".

## Raport
- Odrzucone oferty wypisz osobno z powodem (angielski / wymóg B2+ / stacjonarnie / niedopasowanie).
- Bez duplikatów; przy każdej ofercie link i data publikacji.
