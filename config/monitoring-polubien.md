# Monitoring polubień

- Źródło: aktywność konta Marcina → reakcje (polubienia), tylko odczyt.
- Co raportować: nowe polubione posty od ostatniego raportu, pogrupowane tematycznie
  (AD / Windows Server / Claude i AI / cyberbezpieczeństwo / inne), z linkiem i krótkim streszczeniem.
- Wnioski: powtarzające się tematy i autorzy → propozycje tematów postów oraz kandydaci do komentarza.
- Zapis: `raporty/RRRR-MM-DD-polubienia.md`.
- Nie reaguj i nie komentuj w imieniu Marcina bez zatwierdzenia.
