# Profil postów

## Tematyka
- System Administrator, Windows Server, Active Directory (GPO, DNS, migracje)
- Claude / AI w pracy administratora
- Cyberbezpieczeństwo (w tym PKI, hardening)
- „Co robię / co piszę" – krótkie relacje z własnych projektów i narzędzi
- Ciekawostki i newsy branżowe z powyższych obszarów

## Ton i forma
- Język: polski (domyślnie)
- Praktycznie, rzeczowo, z perspektywy praktyka; bez korporacyjnego bełkotu i bez przesadnych emotek
- Długość: 600–1200 znaków, mocny pierwszy wiersz, na końcu pytanie lub wniosek
- 3–5 hashtagów na końcu
- Nie ujawniaj danych wewnętrznych pracodawcy (nazwy serwerów, domen, liczb z produkcji, incydentów)

## Rytm
- Do ustalenia (propozycja: 1–2 posty tygodniowo)
